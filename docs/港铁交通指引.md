# 港铁线路、换乘与出口指引

2026-10-22 本地功能更新。港铁使用线路名与颜色，页面显示“荃湾线（红色）”等名称。

## 使用

在“问一问 · 排行程”侧栏选择“每日出发港铁站”，再生成行程。首站前显示从该站出发的线路、方向、乘坐站数、换乘站、出口与后续步行／巴士／缆车。也可接着说“改成从尖沙咀站出发”，保留地区、天数与必去地点。这个站用于每天出发，不推测酒店位置。首站时间指抵达景点，酒店到站和首程交通需另预留。

每个景点有可展开的到站接驳，每段转场有交通步骤及来源。下载文本包括相同指引、来源链接和核对日期。旧历史读取时补充新版交通参考，原始记录及时间表不改；页面明确提示重新规划以更新时间。

未填出发站时只给首站的到站出口和后续接驳，不编造上车位置。邻近景点采用步行，山顶说明山顶缆车；昂坪／大澳说明新大屿山巴士 23／11／21 号。没有对应依据时不生成站台号、车门号、票价或班次。

## 数据和计算

`data/transit.json` 独立于景点检索语料，含 33 个地点的到站接驳、6 条线路、85 个支持站点、可用换站通道和来源。来源核对日 2026-10-22。线路为荃湾线、港岛线、观塘线、东涌线、屯马线及东铁主线路径；并非完整香港公交网络，不覆盖机场快线、轻铁及所有特殊支线。

`travel/transit.py` 按（车站、线路）构建连接，Dijkstra 寻找本地权重较小的路径。相邻站余量按 3 分钟、普通换乘按 8 分钟；地下通道换站另设步行／出入闸余量。这里是规划权重和时间假设，不是官方公布的乘车时长。方向由线路的对应终点确定；连续同线步骤合并并列出实际站序，站数不把出发站算进去。不同车站的地下通道换乘明确单列，尖沙咀／尖东不会被当作同一个付费区车站。

目的地有多个有依据的出口方案时，综合两端步行与线路权重选择候选；不宣称最快、最少步行或无障碍。附近地点不强行乘地铁；没有街道级算路时仅给步行衔接及边界。

`official_exit_listing` 表示目的地在站图或运营方交通资料列有出口；`station_map_reference` 表示根据站区图及地点地址人工整理街面衔接。后者不冒充官方逐步导航。步行时长为项目估算，不把地图上的直线连线作为步行路线。

公开网页和不同版本站图存在出口差异，按具体来源分别保存：动植物公园采用其官网中环 D2；西九优先保留九龙 C1，柯士甸 D1 作为新站图参考；不把旧 B4/B5 描述拼入新出口路径。公交尾班、出口临时封闭和施工通道仍需出发前核对。

## 接口

- `POST /api/transit/route`：`{"origin_station":"尖沙咀","destination_id":"nan-lian"}`。
- 也可传 `{"origin_id":"star-ferry","destination_id":"art-park"}`。两种起点互斥。
- 不传起点时返回到站后的出口接驳，`missing_origin=true`。
- `/api/chat` 的 `trip.start_station`、`/api/plan` 与本地 MCP `plan_itinerary` 支持同名参数；历史中保存选择。
- 以上港铁交通指引不依赖模型或高德 Key，不请求实时路线。高德地点补充搜索已在后续统一搜索更新中按用户要求启用，路线服务仍需单独验证。

## 验证边界

测试覆盖直达、换乘、返程方向、站数、出入闸换站、首站缺失、非法输入、33 个地点覆盖、缆车／巴士接驳、历史只读补充与真实 stdio。浏览器验收包括选择出发站、含换乘的行程、来源、下载与刷新恢复。以上不构成实际出行精度或运营状态验证。
