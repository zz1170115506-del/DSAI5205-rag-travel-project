# 最近对话管理验收

2026-10-22，本地开发，Codex 辅助完成。未推送公开仓库。

## 功能

- 每段历史有收藏、置顶与删除按钮，图标常显，具有操作名称及当前状态；收藏后星标高亮，置顶后图钉高亮并显示左侧标记。
- 全部／收藏筛选及收藏数，空收藏有提示；筛选不会更换当前聊天内容。
- 置顶优先，组内按最后聊天时间排序；取消置顶恢复时间顺序，元数据操作不改最后聊天时间。
- 收藏、置顶在 SQLite 保存，刷新、重启、继续聊天仍有效。旧四列数据库增加默认 false 的两列，保留原始 payload 与 ID。
- 删除先弹窗，显示标题、不可恢复说明；默认焦点在取消。确认才请求删除；取消保留历史。删除当前对话会打开空白新对话，删除其他对话不清空当前内容。
- 请求失败提示，更新时禁用历史操作；收藏筛选中取消最后一个收藏后，焦点回到收藏筛选按钮。

接口 `POST /api/history/update` 接收 `id` 和布尔 `favorite`／`pinned`，允许部分更新。ID、字段和类型严格验证，找不到记录返回 404。API 仅返回状态，不返回对话正文。保存新轮次使用 UPSERT，只更新聊天字段，保留两项状态。
