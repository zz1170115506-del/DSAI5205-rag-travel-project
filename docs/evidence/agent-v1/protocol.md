# Agent v1 验收协议（实现前冻结）

2026-10-19。人工开发验收，不是独立基准，不代表真实模型准确率。原检索保留集 SHA256：01c5e215f9fa3f45b28707fe5ef8c3caa5ea4c42935b426cfdb62c99e043a31b；不修改该集或检索排序。

比较对象：原固定检索/规划接口与新增 LangGraph 会话接口。原接口无会话条件继承；不把模拟决策计为真实模型收益。

验收场景：
1. 无 Key，九龙一天、少走路；下一轮只改为室内，保留区域/天数/节奏。
2. 不同会话条件不串；删除会话后旧 id 无法续接。
3. 工具未知、参数非法、超时和空检索均有可读错误反馈；模拟策略根据反馈修正再执行。
4. 必去地点与室内条件冲突不静默放宽；要求用户修改条件。
5. 模拟模型自选 search → detail → finish，实际工具结果反馈下一次决策。
6. 重复调用/无限调用在上限终止；一次请求总超时、模型次数、工具次数可审查。
7. 未配置/未勾选模型零外部请求；涉及动态信息先阻止模型请求。
8. 非法引用、不可信工具文本和异常字符串不泄露秘密或产生假来源。
9. 历史有限、会话有容量/过期限制、同会话串行；清除与服务重启的内存边界明确。
10. 完整继承回归、真实 stdio、网页会话/续问/重置主流程。

记录调用顺序、状态、有效参数、耗时、模型请求次数/工具次数、恢复事件、终止原因。无服务端用量时费用为 null，不编造成本或真实模型表现。
