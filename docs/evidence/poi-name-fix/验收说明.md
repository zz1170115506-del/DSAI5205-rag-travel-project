# 元创方到半山扶梯：高德地点匹配修复

日期 2026-10-23，资源 1.3.21。

## 原因与修复

真实查询“元创方 PMQ”返回“PMQ元创方”（鸭巴甸街35号），同时有名称包含该景点的店铺。旧算法仅比较完全相同的字串，因此把真实景点拒绝。全名“中环至半山自动扶梯”查询为空，但已有别名“半山扶梯”返回同名规范地点。

名称规范化：全角转常用字符、已有简繁映射、提取完整中英文块后比较，兼容空格、括号及英文缩写前后顺序。并非任意模糊命中或子串命中；SOIL(PMQ元创方店) 不等价于景点，测试验证其拒绝。等价名称若对应多个 POI，仍保留所有候选交给用户确认，不自动选其中一个。

## 真实网页结果

独立 8768 服务、独立 SQLite，模型关闭，网页输入“只去元创方 PMQ和中环至半山自动扶梯，安排一天行程”；展开小地图后自动查询真实高德，返回 339 米、约 5 分钟（供应商估计）、7 段文字步骤，地图 640×400 且已加载。图像放大可用，桌面无横向溢出。没有直接把本地近似坐标传给高德算路。

导航起点：PMQ元创方，114.156867,22.28073；终点：中环至半山自动扶梯，114.158864,22.279343（荷李活道与奥卑利街交叉口北20米，扶梯为线状设施，此点为供应商返回的一个位置）。步骤含鸭巴甸街和荷李活道。

证据：`browser-live-route.json` 与 `browser-pmq-escalator.png`。原主站已加载新版；无需删除对话或重新生成原行程。未将实际用户历史用于模型测试。
