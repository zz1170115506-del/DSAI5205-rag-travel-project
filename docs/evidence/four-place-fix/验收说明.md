# 四地点规划修复验收

2026-10-23，资源版本 1.3.18。

## 改动

取消三个必去地点的业务限制：前端卡片、多选表单、HTTP 请求、Agent 完整条件与补丁、本地指代及规划器同步移除。所有已选地点仍必须是规范库内 ID，地区／室内／排除条件继续校验。整组选择保存在结构化条件中；不以备注代替第四处。

规划先为每个必去街区按每日节奏预留容量，再安排可选地点。必去地点分批跨日，最终核对全部入选且不重复；日期不足说明需要的天数，不静默截断。此天数是街区／数量约束的最低值，交通与停留仍为估算，不能当作现实营业日历或最优路线保证。

失败提示注明实际调用上限；缺少天数且模型文字不合格时，保留选择并询问天数或起止日期。

## 真实网页七轮

独立 8768 服务、独立 SQLite 合成对话，高德关闭。所有输入由浏览器控件填写并发送，真实配置模型选择工具，未模拟模型回答或直接调用聊天接口。

| 轮次 | 连续输入重点 | 实际结果 |
| --- | --- | --- |
| 1 | 爸妈同行、轻松，只去扶梯／元创方／兰芳园／动植物公园，先记住 | 四处全部写入选择，only_selected=true |
| 2 | “请帮我把这几个地点串成行程” | 选择保留，日期未确认；模型文字校验触发摘录保底（见限制） |
| 3 | “玩两天” | 第一天元创方＋扶梯，第二天动植物公园＋兰芳园；四处完整 |
| 4 | 把公园移第一天，保留其余三处和第二天 | 第一天三处，第二天兰芳园；四处完整 |
| 5 | 元创方换大馆，其余三处不变，元创方以后不排 | 大馆替换元创方，选择仍四处，元创方加入排除 |
| 6 | 刷新后“前后两天互换” | 第一天兰芳园，第二天大馆＋扶梯＋动植物公园 |
| 7 | 回顾地点、同行者、节奏、排除地点 | 回答四处、爸妈、轻松及元创方不再安排 |

`browser-seven-turns.json` 为逐轮 DOM 读取的回答、逐日地点、工具轨迹及八项检查，全部检查通过。七轮 stop_reason=complete，每轮 external_model_verified=true，工具事件全部 success，未达到调用上限。

不能把工具成功等同于每次模型成文合格：第二轮模型成文未通过校验，旧保底显示推荐摘录；随后增加了按当前四处选择询问天数的保底并通过单测。第三轮展示成功的真实工具草案与本地摘要。第五轮存在一次不再执行工具的 JSON 格式修复；保留真实记录，没有隐藏重试。后续移动、替换、交换、回顾均完成。这组测试不是独立准确率评测。

另以新合成对话，在旅行偏好多选四处、勾选只安排已选、填 2026-11-07 至 2026-11-08 并点击规划；本地模式网页核对四处全部展示。
