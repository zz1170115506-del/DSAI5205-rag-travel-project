# 给小组成员访问的公网演示

已准备 Render 配置和访问保护，尚未完成真实云端构建与部署。部署成功后，组员通过 HTTPS 网址访问，不依赖组长电脑开机。GitHub 保存源代码，Render 运行 Python 后端和网页。

## 演示范围

- 全部页面、接口和历史使用一组演示用户名／密码。组员可以查看、修改和删除共享历史，只输入小组演示资料；当前没有个人账号和历史隔离。
- 云端新建自己的历史，不上传电脑上的 `.env`、`work/`、本机历史或密钥备份。
- 模型／地图入口请求合计每分钟最多12次，公网演示一次只处理一个此类请求，以降低免费实例的内存压力。一个问答可能调用模型多次，这不是供应商额度或费用上限。
- 免费 Render 有休眠、启动等待、内存和用量限制；SQLite 历史在重启、重新部署或休眠后可能丢失。Embedding 权重与索引在构建阶段准备，云端资源是否足够仍须实测。

## 部署步骤

1. 将已检查的源码和 `render.yaml` 推送到 GitHub。仓库可以保持私有，无需公开源码。
2. 登录 [Render](https://dashboard.render.com)，选择创建 Blueprint，连接本项目仓库。GitHub 授权只选择本项目；扩大授权范围需由账号本人确认。
3. 核对：一个 **Free Web Service**，Singapore 区域，Python 3.14.7，健康检查 `/healthz`；自动部署关闭，之后手动发布。遇到付费升级或付款信息时先停止核对，不自动购买套餐。
4. 在平台私有环境变量中填写下表。其他模型与 Embedding 配置已写入 Blueprint，网址使用平台提供的 `RENDER_EXTERNAL_URL`。

| 变量 | 内容 |
| --- | --- |
| `DEMO_USERNAME` | 默认 `team` |
| `DEMO_PASSWORD` | 单独生成的随机访问密码，至少16字符，不使用账号密码或 API Key |
| `MODEL_API_KEY` | 魔搭访问令牌 |
| `AMAP_API_KEY` | 高德 Web 服务 Key |

密钥只填平台环境变量，不能写进 GitHub 文件。把本机 Key 保存到 Render 是新的云端凭据传输，应由本人确认后完成。

5. 最终核对服务计划、授权范围和环境变量后开始部署。构建会安装依赖并下载公开 BGE 模型；国内接口从云端是否可用也须实测。
6. 打开生成的 HTTPS 网址，输入小组用户名／密码，验证检索、模型回答、地图补充及出处。通过后将网址与演示账号交给组员，不分享模型或地图 Key。

## 启动与访问保护

`run.py` 继续只监听本机。云端使用 `python scripts/serve_public.py`，读取平台 `PORT`，单进程启动。缺少 `PUBLIC_DEMO=true`、固定 HTTPS 网址或合格密码时拒绝绑定公网服务端口。

Host 仅允许本机及配置网址的主机名，写请求的 Origin 与固定公网网址匹配。`/healthz` 仅返回 `{"status":"ok"}`；其他页面与接口要求 HTTP Basic 认证。不要直接将本机无密码入口映射到公网。

## 上线验证

- 未登录访问首页、状态、历史应返回401；健康检查只返回最小状态。
- 登录后同源问答正常，跨站写请求被拒绝；模型／地图请求限流生效。
- 实测云端 Embedding、魔搭和高德；不把 BM25 回退当作向量检索成功。内存或网络不满足时，不自动升级付费服务。
- 检查真实用量与平台套餐。当前本地访问测试通过，公网地址需真实部署并验证后才能交付。
