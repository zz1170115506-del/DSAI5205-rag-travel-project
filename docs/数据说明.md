# 资料来源与维护规则

- 版本：2026-10-19.1；21 条地点记录。
- `summary` 是依据各记录的 `source` 官方页面人工概述的文字，不是整页复制。
- `source_title`、`source`、`checked` 用于追溯来源。核对日不代表餐厅仍营业，也不代表票价或开放时间已核实。
- `tags`、`cluster`、`duration`、`priority`、`indoor` 与 `cost` 是本项目的规划标签或假设，不能描述成官方认证。
- `indoor=true` 只表示有室内参观／用餐空间，不能保证到达、排队或整个场地都避雨。
- `cost=public` 仅供公共空间筛选；不包含交通和餐饮。`mixed` 表示公共区域与部分收费体验需要区分；`ticket` 保守视为应核实门票的场馆；`meal` 是餐饮候选。
- `lat` / `lon` 是人工近似 WGS84 地点示意点，没有用测绘或地理编码逐点核验。不可作为精确导航、距离实测或高德坐标使用。高德实际搜索按地点名称进行，不直接使用这些坐标。
- 路程估算不是事实资料：城区使用直线距离、人工绕行系数、速度和固定余量；山顶和昂坪至大澳另加保守余量。它不能代替公共交通或步行导航。
- 本版本不保存完整网页、用户个人位置、API Key、问答历史、菜单价格或天气数据。最近行程仅保存在用户自己的浏览器 localStorage 中。

扩充资料时，请先访问官方或运营方页面，写简短概述并记录链接与日期；不能从 GitHub README 的宣传文字直接生成“已实现”或“已验证”的项目结果。
