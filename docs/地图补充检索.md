# 地图补充检索与 RAG

本功能接入已有的高德 Web 服务适配器：本地搜索未命中、用户明确询问未收录的地点，或类别推荐没有足够的合适结果时，先按香港范围查询地图候选，再在模型模式下把有限字段提供给模型生成回答。外部结果不加入本地知识库或向量索引。

## 本地配置

从 [高德控制台](https://console.amap.com/dev/key/app) 获取 **Web 服务** 类型 Key，在根目录私有 `.env` 填写：

```dotenv
AMAP_API_KEY=
AMAP_ENABLED=true
```

保留已有 `MODEL_API_KEY`、`MODEL_BASE_URL`、`MODEL_NAME` 和本地 Embedding 配置。两个平台的 Key 不能互换，不提交真实 `.env`。保存后重启应用；勾选网页“使用大模型”才会把地图候选发送给模型服务。高德 API 权限、香港覆盖、费用和额度以本人账号及服务为准。

## 实际流程

1. 原有本地检索与 Agent 正常处理问题，已收录地点继续使用本地官方来源资料。
2. 地点检索未命中、明确指定未收录地点，或商场／博物馆推荐缺少足够的同类候选时，最多发起一次高德香港关键词查询，最多保留五个候选。类别推荐默认目标为三个候选；用户明确指定数量时采用该数量，查询目标上限为五个，不承诺补满。
3. 商场／购物中心与博物馆按明确类别过滤；“购物”标签、语义相似的文化景点不等于商场。地图结果还校验香港位置、地区、来源及字段长度，剔除商场内的停车场、餐厅等不同类别设施，生成本次回答专用的 `map-1` 等引用编号，来源链接由服务端构建。
4. 已开启模型时，把名称、地址、类别和查询时间作为不可信参考资料提供给模型。不开启模型时，仅显示地图候选。
5. 校验正文引用与返回编号；有效回答标为“模型＋地图资料”，引用可打开高德地点页。地图请求、生成和失败原因记录在执行记录中。

示例：“K11在哪”继续按具体名称查询；“九龙有哪些商场”整理成“香港 九龙 商场”，“旺角有哪些商场”整理成“香港 旺角 商场”。具体地区优先于旧行程地区。即使本地返回艺术馆、购物街，也不会将其作为商场推荐或据此阻止地图补充。它们是否返回候选取决于高德服务；示例不代表已实测命中。不指定类别的普通问题沿用原有本地优先逻辑，不自动遍历地图。

## 信息边界和失败处理

- 地图目前只提供名称、地址、类别与位置，不据此推断历史特色、营业时间、票价、天气、室内或免费条件。地区筛选保留；无法证明满足室内／免费条件时，不静默放宽偏好。
- 关键词检索不代表真正的周边距离排序；同名分店仍需用户确认。当前没有地图结果的语义向量检索或神经重排。
- 地图 Key 未配置、未启用、无结果、超时或平台拒绝时，不调用地图资料生成。模型失败或引用不合格时保留原始候选，明确提示失败。
- 补充检索失败时保留已经确认符合类别的本地候选，不用其他类别凑数。`external_lookup.coverage` 记录本次有界目标数量及本地、地图候选数，`exhaustive=false` 表示不是香港全部地点的清单。
- 外部 POI 不自动加入规范地点列表、偏好或行程排程；“把第二个加进行程”等外部地点追问尚不支持。历史会保留已显示的候选与回答，但下一轮需要地图事实时应重新检索，不把历史文字当作已验证的新证据。
- 地图补充在主 Agent 之后运行，单次地图资料生成最多约 20 秒，整轮补充受剩余时间限制。外部调用有实际用量，不配置付费服务的自动回退。

## 验证与当前状态

自动测试使用 HTTP 模拟响应，验证“地图返回字段确实进入模型请求”、引用校验、HTML／链接处理、地区和偏好筛选、失败回退、不开模型不发生成请求及历史恢复。模拟通过不表示真实高德接口已连通。2026-10-27 已另行完成真实验证：高德查询 K11 MUSEA 约 1.9 秒返回五个候选；完整网页问答约 27.7 秒，其中地图资料生成约 4.8 秒，`map_rag_used=true`，网页显示“模型＋地图资料”及地图出处链接。343 项 Python、22 项前端检查通过。见 [脱敏验证记录](evidence/map-rag-2026-10-27/summary.json)。这是单例连通性验证，不是准确率或稳定延迟基准。

主要实现为 `travel/place_intent.py`、`travel/map_rag.py`、`travel/chat.py`、`static/answer-citations.mjs`。类别与天数修复的针对性回归见 `tests/test_intent_fixes.py`；模拟响应不代表真实平台验证。官方接口：[高德 POI 搜索文档](https://lbs.amap.com/api/webservice/guide/api/search/)。
