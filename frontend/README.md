# 前端

此目录用于接入前端同学已有的应用代码。

## 导入方式

1. 如果原项目已有 Git 提交历史，先与组长确认迁移方案，保留原项目和历史记录。
2. 普通源码目录可复制到这里，让 `package.json`（如有）直接位于 `frontend/package.json`。
3. 导入源码、静态资源、依赖清单以及原项目使用的依赖锁文件。
4. 本地 `node_modules/`、构建产物、真实 `.env` 和另一个仓库的 `.git/` 目录无需复制。
5. 在本文件补充技术栈、运行环境、依赖安装命令和启动命令，沿用现有项目的包管理器。

## 接口联调

- 先与后端在 `../docs/api.md` 中约定接口。
- 后端地址的配置变量由实际前端框架决定；导入代码后提供不含密钥的 `.env.example`。
- 模型服务的真实 API Key 保存在后端，前端通过后端接口调用功能。
