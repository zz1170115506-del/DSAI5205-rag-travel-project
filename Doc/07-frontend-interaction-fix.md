# 前端交互修复与验证

日期：2026-10-24。访问地址仍为 http://localhost:8080/。

## 问题复现

在用户当前页面检查到服务就绪，实际发送问题可以得到真实模型回答。原交互中，示例和景点提问按钮仅填写输入框；景点详情在小屏可能出现在当前视野外；新建空会话没有明显区别；等待期间聊天区接近空白，失败提示也不持久。这些行为让操作看起来没有生效。

## 已修复

- 示例问题和景点详情中的提问按钮直接发起问答，并定位到聊天区域。
- 手动发送和 Enter 共用发送流程，兼容没有 crypto.randomUUID 的浏览器环境。
- 显示发送/理解/检索/生成阶段和经过时间；首个正文片段替换等待提示。
- 停止、补充提问、新建会话、恢复会话具备明确状态反馈，避免重复创建和旧流覆盖。
- 请求与流式读取有时间限制；错误留在消息中，可重新提问，不再只有短暂提示。
- 景点卡片具备键盘操作和选中状态，小屏选中后滚动到详情。
- 检索中显示加载状态并暂时锁定结果区，完成后提示结果数。
- 引用按钮在页面内显示检索原文。synthetic / example.invalid 不再跳到无效外链；真实来源可继续打开。
- JS/MJS 的 MIME 和缓存策略已配置，更新后不会依赖用户手动清缓存。
