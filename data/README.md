# 数据目录

| 目录 | 放置内容 | Git 管理方式 |
| --- | --- | --- |
| `raw/` | 原始旅行资料、网页导出、PDF 等 | 默认仅保存在本地 |
| `processed/` | 清洗、结构化或切分后的数据 | 默认仅保存在本地 |
| `indexes/` | 向量索引或其他检索生成文件 | 默认仅保存在本地 |

这些目录已配置忽略规则，仅保留 `.gitkeep`。资料更新后，应通过明确的共享来源同步，或使用脚本重新生成处理结果和索引。

团队确定资料后，在下方补充来源清单，方便组员获得同一份数据：

| 资料名称 | 来源链接或共享位置 | 获取日期/版本 | 本地保存路径 |
| --- | --- | --- | --- |
| 待补充 | 待补充 | 待补充 | `data/raw/` |

如需提交少量可公开的演示数据，先明确文件、用途与大小，再单独调整对应的忽略规则。
