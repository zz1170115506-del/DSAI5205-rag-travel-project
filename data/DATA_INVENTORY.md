# 数据准备清单

状态：字段及采集计划，尚未采集真实景点数据。先准备 10 个审核样本打通流程，再扩大到 50—100 个景点。数量为首版目标，不限制后续扩充。

## 1. 需要哪些数据

| 数据集 | 首版目标 | 谁准备/如何获得 | 必须信息 | 用途 |
| --- | --- | --- | --- | --- |
| 景点实体与详情 | 50—100 个 | 人工核对旅游机构/景点官方资料 | 稳定 ID、名称、类别、地址/坐标、简介、来源 | 卡片、地图、筛选、问答 |
| 地区/主题/站点/人群实体 | 按所选景点覆盖 | 官方名称 + 团队受控词表 | ID、类型、中英文名称 | 关系查找与统一过滤 |
| 名称别名 | 每景点按真实资料补充 | 官方译名、常用名、繁简对应 | 别名、语言、对应实体 | 精确匹配与消歧 |
| 实体关系 | 所选景点至少有地区关系 | 人工核对或有依据计算 | 两端实体、关系类型、依据、有效状态 | 一至两跳图检索 |
| 景点图片 | 每景点争取 1—3 张 | 获授权来源/团队自有图片 | 资源位置、来源、授权、说明 | 卡片展示；不用于图检索 |
| 介绍/特色故事原文 | 每景点至少 1 份可信介绍 | 景点官方介绍、可使用的文化资料 | 文本、来源、语言、采集/核对时间 | RAG 证据 |
| 开放时间/票价/建议时长 | 有可靠资料才填 | 官方公告；建议时长可为标明依据的编辑估算 | 单位、适用条件、来源、核对时间 | 规划约束；未知留空 |
| 文本片段与索引 | 自动生成 | 清洗/切分/Embedding/BM25 | 文档 ID、偏移、chunk ID、版本 | 可追溯检索 |
| 用户/会话/任务 | 运行产生 | 服务端生成 | 归属、状态、消息、有效任务 | 多轮、取消、恢复 |
| 用户偏好 | 用户明确表达且允许保存 | 从有效消息提取或用户编辑 | key/value、来源、状态、时间 | 长期个性化 |
| 评测样本 | 首批约 100 条 | 人工编写、核对；模型仅辅助起草 | 问题、相关片段、标准事实、约束、类别、split | 对比与迭代 |
| 实验结果 | 每次实验产生 | 评测脚本 | 逐题输出、引用、指标、模型/数据版本、耗时 | 报告与复现 |

## 2. 采集来源候选

以下仅作为待核对候选入口，尚未承诺可批量采集或再分发。实际使用前记录具体页面和条款；入口链接不能代替事实的具体来源。

| 资料类型 | 候选入口/渠道 | 登记内容 |
| --- | --- | --- |
| 景点概况 | 香港旅游发展局、各景点官网 | 具体 URL、标题、语言、获取日期、使用方式 |
| 博物馆与文化资料 | 康文署及博物馆官方资料 | 事实出处、故事段落、核对日期 |
| 地理位置/地区 | 官方地址及可使用的地理资料 | 坐标系统、定位方法、精度 |
| 交通站点 | 港铁等运营方公开站点资料 | 站点名、坐标、核对日期；不代表实时交通 |
| 图片 | 景点授权资源、可再用图片、团队拍摄 | 作者、授权/条款、署名要求、原始页 |

采集台账在 `templates/sources.csv` 填写。若来源不允许保存全文，可记录链接及允许使用的摘录，不能默认把网页图片当成可自由再分发资源。

## 4. 填写与质量规则

1. UTF-8；CSV 时间用 ISO 8601，带时区。数据库统一 UTC，香港开放时间按 Asia/Hong_Kong 解释。
2. 经纬度为 WGS84；来源若为其他坐标系，先记录并转换，不能混用。
3. 不把空值当作 0/免费/全天开放。金额单位 HKD；时长单位分钟；距离单位米。
4. 实体 ID 使用稳定前缀标识，例如 attr_0001、district_0001；不能因名称变化重建 ID。
5. 故事、票价、营业时间和关系必须能追溯来源。冲突资料不直接覆盖，记录核对结果。
6. 首批实体、关系和评测答案人工核验；错误记录进入待修复清单，不静默丢弃。
7. 导入顺序：来源 → 实体 → 别名/景点详情 → 关系/图片/文档 → 片段 → 索引 → 评测引用。
8. 模板中 JSON 列需填写合法 JSON 并按 CSV 规则转义；布尔列仅使用 true/false，空格不表示有效值。
9. 实际导入时发布固定 dataset_version；公开演示样本和评测答案不得混入真实用户个人对话。

## 5. 数据准备验收

- 每个发布景点有可定位名称、有效坐标、简介与具体来源；缺失者不进入地图可发布集合。
- 关系外键、片段来源和图片授权信息完整；发布前校验坐标范围及香港合理位置。
- 相同 ID 重复导入不增加重复记录；变更记录更新内容版本。
- 所有评测引用的 chunk ID 存在于指定快照；无答案样本标准答案不虚构事实。
- 样本足以覆盖中文、英文、繁体、别名、地区/主题交集、多轮纠正和记忆覆盖。
